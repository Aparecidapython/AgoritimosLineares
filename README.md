# 🏗️ Estruturas de Dados e Manipulação de Vetores


## 📋 Sobre este Módulo
Este repositório contém a implementação e o estudo de **Estruturas de Dados**, com foco inicial em **Vetores (Arrays)** e **Matrizes**. Este é o pilar fundamental para quem deseja atuar com **Data Science**, pois a manipulação eficiente de vetores é a base para o uso de bibliotecas como *Pandas* e *NumPy*.

## 🧠 Conceitos Aplicados
Neste repositório, exploro como organizar informações de forma eficiente:

* **Vetores (Arrays Unidimensionais):** Armazenamento sequencial de dados e acesso via índices.
* **Matrizes (Multidimensionais):** Estruturas para representação de tabelas e processamento de imagens.
* **Algoritmos de Busca:** Localização de elementos dentro de vetores.
* **Ordenação:** Organização de dados (Crescente/Decrescente) para otimizar a análise.
* **Complexidade de Tempo:** Primeiros passos no entendimento de performance de algoritmos.

## 🛠️ O que há nos códigos?
1.  **Criação e Leitura:** Como preencher vetores dinamicamente.
2.  **Operações Matemáticas:** Cálculos de média, soma e filtragem de valores em arrays.
3.  **Desafios de Lógica:** Resolução de problemas clássicos de estrutura de dados.

## 🚀 Por que isso é importante para Dados?
Na transição para **Data Analytics**, entender vetores me permite compreender como os dados são estruturados antes de entrarem em um Dashboard ou Modelo de IA. É a base técnica que garante que eu saiba o que acontece "por baixo do capô" das ferramentas de BI.
